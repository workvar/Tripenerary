## v1.1.1

Play Store upload retry for the v1.1.0 build: same app features, with corrected Play “what's new” packaging and draft-track publishing so the signed AAB can land in Google Play Console.

### Highlights

- **Play upload fix.** What's-new file renamed to `whatsnew-en-US`; uploads default to `draft` status (required while the Console app is still in draft).
- **Republish workflow.** `Publish Play Store AAB` can re-upload an existing release AAB without a full native rebuild.
- **Same product as 1.1.0.** Firebase auth/sync, offline attachments, builder Google login, and signed Play builds.

### Added

- `.github/workflows/publish-play.yml` for `workflow_dispatch` Play republish from a GitHub Release tag
- Play service-account JSON parse check before upload

### Changed

- Default Play release `status` is `draft` (`PLAY_STORE_STATUS` overrides)
- `changesNotSentForReview` enabled for first Console uploads
- Version bump to `1.1.1` / `versionCode` `10101` for a clean Play versionCode advance

### Upgrade notes

- Prefer this build over `1.1.0` for Play Console; signing and package id are unchanged.
- If a draft `1.1.0` edit exists in Play Console, discard or complete it before promoting `1.1.1`.
- After Play accepts the draft, finish store listing / Data safety checklist items, then promote the internal track when ready.
