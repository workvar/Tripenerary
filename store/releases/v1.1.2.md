## v1.1.2

Retry Play Store publish with GitHub Actions wired to the **Production** environment so `GOOGLE_PLAY_SERVICE_ACCOUNT_JSON` and the other Environment secrets are available to the upload job.

### Highlights

- **Environment secrets.** Build and Play jobs use the `Production` GitHub Environment (override with `PLAY_STORE_ENVIRONMENT`).
- **Same app as 1.1.1.** Firebase auth/sync, offline attachments, builder login, signed AAB/APK.

### Added

- `PLAY_STORE_ENVIRONMENT` variable support (default `Production`) for both release and republish workflows

### Changed

- Release Android `build` and `play-store` jobs now select a GitHub Environment before reading secrets
- Version bump to `1.1.2` / `versionCode` `10102`

### Downloads

| Platform | Asset |
| --- | --- |
| Android App Bundle (Play) | `tripenerary-1.1.2.aab` |
| Android APK | `tripenerary-1.1.2.apk` |

### Upgrade notes

- Ensure `GOOGLE_PLAY_SERVICE_ACCOUNT_JSON` (and signing secrets) are on the **Production** Environment in GitHub → Settings → Secrets and variables → Actions → Environment secrets.
- Invite that service account in Play Console → Users and permissions with release access for `com.tripcompanion.app`.
- First successful upload lands as an **internal** track **draft**; promote in Play Console when listing checklist items are done.
