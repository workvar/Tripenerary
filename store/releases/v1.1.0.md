## v1.1.0

First Google Play–ready release of Tripenerary: signed Android builds, Firebase sign-in and cloud sync, offline document caching, and a builder login flow so published trips stay in sync from edit to phone.

### Highlights

- **Play Store publish pipeline.** Pushing a `v*` tag builds a signed APK and AAB, creates a GitHub Release, and uploads the AAB to Google Play when configured.
- **Firebase auth and cloud sync.** Sign in on mobile and in the builder; trip libraries sync through Firestore and Storage under `cloudSync` / `useAuth`.
- **Offline attachments.** Tickets and booking PDFs download once and open offline via the attachment cache (`useAttachment`, `src/lib/cache`).
- **Builder Google login.** The web builder has a dedicated login page with Google sessions, brand favicon, and publish/emergency links.
- **Maps keys stay out of git.** `GOOGLE_MAPS_ANDROID_KEY` is injected at build time; Expo config and env examples are split for mobile vs builder.

### Added

- GitHub Actions workflow `.github/workflows/release.yml` — typecheck, `assembleRelease` / `bundleRelease`, GitHub Release assets, Play upload job
- Firebase client setup (`src/lib/firebase.ts`), auth hook (`src/hooks/useAuth.tsx`), and cloud sync (`src/lib/cloudSync.ts`)
- Offline PDF / document cache under `src/lib/cache/` and `src/lib/attachments.ts`
- Builder login page with Google auth and sessions
- Store listing copy and Data safety answers in `store/LISTING.md` and `store/DATA_SAFETY.md`
- Play / Galaxy release checklist in `docs/RELEASE.md`
- Day picker sheet and richer Thailand sample itinerary

### Changed

- Trip library and settings screens support signed-in sync and attachment status
- Env examples split: mobile `.env.example` vs `builder` env; Play signing notes restored for mobile
- Android package and signing path prepared for `com.tripcompanion.app` upload keystore
- Sample itinerary (`sample/thailand-sample.json`) expanded with stays, mapped locations, and attachments

### Upgrade notes

- Existing installs from sideloaded `1.0.0` builds should uninstall first if the signing key changed to the Play upload keystore.
- After updating, open **Settings** to sign in if you want cloud sync; local trips keep working offline without an account.
- Maps require a valid `GOOGLE_MAPS_ANDROID_KEY` restricted to the upload-key SHA-1 used for this release.
