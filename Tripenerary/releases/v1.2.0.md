## v1.2.0

New Android application id for Google Play: `com.workvar.tripenerary`. This clears Play Console conflicts with another developer’s reserved content-provider authorities under the old `com.tripcompanion.app` package.

### Highlights

- **New package name.** `applicationId` / namespace / Play `packageName` are now `com.workvar.tripenerary`, so FileProvider and androidx-startup authorities become `com.workvar.tripenerary.*`.
- **Deep link scheme.** Android intent scheme updated to `tripenerary`.
- **Same product.** First-release feature set unchanged — see `store/whatsnew/whatsnew-en-US`.

### Changed

- `app.json` `android.package` and iOS `bundleIdentifier` → `com.workvar.tripenerary`
- Native Kotlin package moved to `com.workvar.tripenerary`
- GitHub Actions Play upload `packageName` and release docs updated
- Version `1.2.0` / `versionCode` `10200`

### Upgrade notes

- Create a **new** Play Console app with package `com.workvar.tripenerary` (this is not an update to the old `com.tripcompanion.app` listing).
- Restrict the Google Maps Android API key to the new package + upload/App Signing SHA-1s.
- If Firebase Auth is used, register an Android app with package `com.workvar.tripenerary` and refresh config secrets.
- Invite the Play service account on the new app’s Users and permissions.
- Upload `tripenerary-1.2.0.aab` with first-release notes from `store/whatsnew/whatsnew-en-US`.
